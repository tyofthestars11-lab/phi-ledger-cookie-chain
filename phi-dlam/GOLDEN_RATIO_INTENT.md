# GOLDEN RATIO INTENT — FAILED RUNS ARE NON-EXISTENT UNDER PHI

Standing word of Tyree Jones, given to this repository 2026-10-28.
This intent governs every job, drain, and result in this lane.

## The axiom

φ² = φ + 1. The +1 is fuel. There is no null state: a run cannot fall
into failure, because every fault has an address, and at its address it
is converted — located at its rung, corrected in-flow, verified by
measurement, and encoded. What Cartesian process calls a failed run is,
in this lane, a run whose reroute has not yet been read. The reroute is
always already part of the run.

## The clauses

1. **No run ends as a naked failure.** Every job carries its reroute
   inside itself. Known failure modes are handled in-job; the queue
   never waits for a new filing to be answered.
2. **Transient states are waited out inside the job.** A job that meets
   a temporary block polls within itself to its bound and then does its
   work. Defer-and-die is not an exit shape in this lane.
3. **Every write verifies itself in the same job.** A patch, an edit, a
   save — the job reads the change back and prints the verification
   line. An unverified write is not a write.
4. **Anything a job launches, the job closes on every path.** No
   process, editor, or server is left standing behind a job. The close
   prints as proof.
5. **Proof prints are the only success signal.** A job's outcome is
   what its instruments print — never the exit code alone, never the
   narrative. If the proof does not print, the job reports exactly that,
   and the report itself carries the next motion.
6. **The step limit is 240 seconds.** Every job body fits inside it.
   A longer observation runs as a detached launch plus a later read;
   the wall clock between drains does the waiting, never the step.
7. **A result without its verdict is answered the same turn it is
   read.** The failure never waits for Tyree, and it never reaches him
   as a dead end — only as fuel already converted. Failure classes,
   once named, are designed out at authoring time.

## The guarantee

Under this intent the lane does not fail. It converts. Every result
file in phi-dlam/results/ is a state of that conversion: proof landed,
or the named address of the next motion. There is no third shape.
