# OMNI RPG: PATH OF LIGHT

Original sci-fi RPG — Prototype 01 foundation, Unreal Engine 5.8 (C++).

One alien world. One abandoned megastructure. An ancient signal. Hostile
machines. Four factions: Void, Scavenger, Guardian, Remnant.

Cyberpunk × GTA × Crimson Desert × Elder Scrolls — built district by
district on a foundation that expands into the full open world.

**Start here:** `OMNI_PROJECT_SETUP.md` — compile steps, input assets,
blueprint list, first level layout, performance targets for RTX 3050 6 GB.

Systems in code: third-person character (move/sprint/dodge/aim/fire/health),
6-state faction AI + territory manager, 4×4 district streaming with LOD
tiers, discovery (clues / artifacts / mysteries / Signal progress), game
phases, difficulty scaling, HUD + pause controller.
